# Gameplay Ability Spec
A *Gameplay Ability Spec* is the instance of it's parent Gameplay Ability. It exists on the *ASC* after a *Gameplay Ability* is granted / activated.
- The editor of the documentation refers to it as *Spec* for a shorter conceptual name.
- [ ] Check if there's two layers or if Tranek means activating the GA creates the activated spec, or if there is separate activation.

## Overview
- *Gameplay Ability Spec*  can be freely created and modified at runtime.
- *Gameplay Ability*  can not, and should be created by designers prior to runtime.
