# Gameplay Ability System
This is the landing page for my modification of Tranek's GAS Docs.
>The actual README.md is used to deploy Obsidian, the software that I used to edit this.


## Canvas
Optionally, a Canvas is a tool in Obsidian that is included by default. While I have preferred the graph view for some time, I demo'ed this feature to some friends by building one for this documentation.

## Overview
- [[About]] - Docs Info
- [[Concepts]] - Tools for designing your game, in terms of things that exist before runtime. Includes how to setup any variables you had for your RPG game / numbers and values you need to represent your ideal gameplay.
> You want to figure out how many of each of these you want to get your rules established. Then design *Calculations* for them to execute from or off of.
- [[Calculations]] - Code GAS Provides for, uh, designing your method of enforcement for calculation.
>These are for designing your own internal mathematical logic for how those *Concepts* you established calculate in your game, literally.
- [[Programming Objects]] - Utility Code I could not find a better place for, like reticles within your level.
 >Not a calculation, more... literal object in view. Right?
- [[More Reading]] - FAQs, Debugging, Optimizing, etc.
>Notes on formatting are here, along with changelogs.
- [[Common Examples]] Included Code with the *Sample Project*
> Common things and seem to be really useful
